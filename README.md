# 🎲✨ بازی نقش رندوم کاربران – HTML/CSS/JS

سلام به دنیای **نقش‌های رندوم و هیجان‌انگیز**! 🚀  
این پروژه یک **سایت بازی نقش رندوم** است که می‌تواند هر جمعی را سرگرم کند. بدون نیاز به سرور، فقط با مرورگر اجرا می‌شود! 🌈💻📱

---

## 🎯 ویژگی‌های ناب

- **صفحه ورود کاربران و مدیر** (`index.html`)  
- **پنل کاربر با نقش رندوم و تایمر 1:30 دقیقه** (`user.html`)  
  - نقش‌ها به صورت تصادفی انتخاب می‌شوند 🎲  
  - کارت نقش با انیمیشن جذاب 🔄  
  - نوار تایمر بصری ⏳  
  - بعد از پایان زمان، کاربر خودکار به صفحه ورود بازمی‌گردد  
- **پنل مدیر با لیست نقش‌ها** (`admin.html`)  
  - تمام نقش‌ها قابل مشاهده هستند 📝  
  - بازگشت سریع به صفحه ورود  
- **گرافیک مدرن و انیمیشن‌های جذاب** ✨  
  - دکمه‌ها و کارت‌ها با حرکت و افکت نرم  
  - واکنش‌گرا و مناسب موبایل 📱
